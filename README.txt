PRÁCTICA 02 - DART
Tipos de Datos: Map, List, Set y más

CONTENIDO
1. ejercicio_list.dart
   Combina dos listas ordenadas en una sola lista ordenada.
   Casos incluidos:
   [1,2,4] + [1,3,4] -> [1,1,2,3,4,4]
   [] + [] -> []
   [] + [0] -> [0]

2. ejercicio_map.dart
   Obtiene la intersección de dos arreglos respetando repeticiones.
   Casos incluidos:
   [1,2,2,1] y [2,2] -> [2,2]
   [4,9,5] y [9,4,9,8,4] -> [9,4]

3. ejercicio_set.dart
   Coloca cada tipo de fruta en la primera cesta disponible,
   de izquierda a derecha, con capacidad suficiente.
   Casos incluidos:
   [4,2,5], [3,5,4] -> 1
   [3,6,1], [6,4,7] -> 0

4. repaso_dart.dart
   Ejemplos de tipos primitivos, List, Map, Set, Records,
   Enum y Null Safety.

CÓMO EJECUTAR
Abra la carpeta en VS Code y, desde la terminal, ejecute:

dart run ejercicio_list.dart
dart run ejercicio_map.dart
dart run ejercicio_set.dart
dart run repaso_dart.dart

Si Dart no es reconocido, ejecute primero:
dart --version
